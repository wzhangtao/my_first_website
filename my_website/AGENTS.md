# AGENTS.md

本文件为 AI 编程助手提供项目工作的关键信息。

## 项目概述

这是一个**数据分析领域的个人介绍网页**，用于展示张涛（数据分析师/数据实施顾问）的专业背景、技能和工作经历。

**语言**：中文（zh-CN）

## 技术栈

- **HTML5**：语义化标签结构
- **CSS3**：现代样式设计，包括：
  - CSS 弹性盒子（Flexbox）布局
  - CSS 网格（Grid）响应式布局
  - CSS 过渡与悬停动效
  - 线性渐变背景
  - 媒体查询实现响应式设计
- **JavaScript**：仅用于移动端汉堡菜单交互
- **无构建工具**：纯静态网站，无需打包
- **无外部依赖**：不依赖任何第三方框架或库

## 页面结构

### index.html
按以下区块组织：
- **导航栏**：固定顶部，含头像和锚点链接（简介/技能/经历/联系方式）
- **首屏封面**：全屏渐变背景，展示姓名、职位和简介
- **关于我**：个人介绍卡片
- **技能栈**：5 个技能标签
- **工作经历**：神策数据实施顾问职位卡片
- **联系方式**：GitHub、邮箱、电话
- **页脚**：版权信息

### css/style.css
包含：
- CSS 变量定义（配色方案）
- 基础重置样式
- 导航栏样式（固定定位、毛玻璃效果）
- 各区块组件样式（首屏、卡片、技能标签、联系方式）
- 响应式媒体查询（768px 和 480px 断点）

### js/script.js
- 移动端汉堡菜单切换
- 点击导航链接后自动关闭菜单

## 设计规范

- **配色方案**：深蓝/青蓝渐变主题
  - 主深色：`#0d47a1`
  - 主色：`#1565c0`
  - 主浅色：`#42a5f5`
  - 强调色：`#00acc1`
- **布局**：单列居中，最大宽度 1000px
- **字体**：系统字体栈，支持中文

- **响应式**：768px 和 480px 断点，移动端汉堡菜单

## 开发指南

### 代码风格
- 使用语义化 HTML5 标签（`<nav>`、`<section>`、`<footer>`）
- CSS 使用类似 BEM 的命名方式（如 `.nav-logo`、`.skill-tag`）
- 注释使用中文
- 缩进统一使用 4 个空格

### 内容修改
- **个人信息**：修改 `index.html` 对应区块的文本
- **技能标签**：编辑 `index.html` 中 `<div class="skills-container">` 内的标签
- **联系邮箱**：更新 `index.html` 中 `<a href="mailto:">` 的链接
- **头像照片**：替换 `photo.jpg` 文件（保持文件名不变）

### 样式调整
- **主题色**：修改 `css/style.css` 中 `:root` 的 CSS 变量
- **首屏渐变**：编辑 `.hero` 的 `background` 属性
- **卡片阴影**：调整 `.card` 的 `box-shadow` 值

## 测试方法

作为静态 HTML 文件：

1. **本地测试**：直接用浏览器打开 `index.html`
2. **跨浏览器测试**：在 Chrome、Firefox、Safari、Edge 中测试
3. **响应式测试**：缩放浏览器窗口或使用设备模拟器
4. **无单元测试**：未配置测试框架

## 部署方式

静态网站可通过以下方式部署：

1. **本地访问**：直接用浏览器打开 `index.html`
2. **Web 服务器**：使用 nginx、Apache 等静态服务器（注意路径配置）
3. **CDN 托管**：上传至 GitHub Pages、Netlify、Vercel 等平台
